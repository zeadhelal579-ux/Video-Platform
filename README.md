# VideoPlatform

منصة لبث الفيديو بجودة بتتكيّف مع سرعة الاتصال. المستخدم يرفع الفيديو مرة واحدة، والـWorker يجهّز نسخ HLS في الخلفية، والمشغّل يختار الجودة أثناء المشاهدة.

## رحلة الفيديو

1. الواجهة بتطلب رابط رفع مؤقت من الـAPI وبترفع الملف مباشرةً إلى MinIO أو S3.
2. بعد تأكيد الرفع، الـAPI بيسجل الحالة في PostgreSQL ويبعت مهمة على RabbitMQ.
3. الـWorker يشغّل FFmpeg، ويخزّن ملفات HLS، ويحدّث حالة الفيديو.
4. المستخدم يشوف فيديوهاته في مكتبته ويشغّل الفيديو لما حالته تبقى `Ready`.
